# Superstore Sales & Profit Analysis Dashboard | Power BI

## Project Overview

This project is an interactive Power BI dashboard created to analyze
sales, profit, customers, orders, products, categories, and regional
performance using Superstore data.

The dashboard is organized into four pages to provide different views
of business performance.

## Dashboard Preview

### Executive Overview

![Executive Overview](screenshots/Executive overview.png)

The Executive Overview provides a summary of key business metrics
including Sales, Customers, Profit, and Orders. It also includes
category performance, regional contribution, sales trends, and
sub-category performance.

### Time Analysis

![Time Analysis](screenshots/Time Analysis.png)

The Time Analysis page focuses on sales and profit trends over time.
It includes PM Sales, MTD Sales, YTD Sales, monthly sales trends,
profit trends, and sales comparisons.

### Product Analysis

![Product Analysis](screenshots/Product analysis.png)

The Product Analysis page is used to study product and sub-category
performance and compare sales and profit across different products.

### Customer Analysis

![Customer Analysis](screenshots/Customer analysis.png)

The Customer Analysis page focuses on customer-related sales and
profit performance and helps compare customer segments and regions.

## Key Analysis

## Interactive Features

The dashboard includes interactive filters and slicers for exploring
the data based on:

- Region
- Quarter
- Category
- Sub-category
- Other available dimensions

These filters allow users to view the dashboard based on different
business requirements.
